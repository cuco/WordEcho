## 编写与复核

逐条检查目标词义、词性、语法、搭配、冠词、可数性、短语完整性、中英对应和儿童语境。所有句子不超过 10 个英文空格分词，以简单现在时为主，适当使用祈使句和情态动词；采用英式拼写。相近题材允许使用常见句式，但每句都根据词义写定，不调用词性套句函数。

本轮特别处理：

| 词条 | 当前义项及例句处理 |
| --- | --- |
| rich | 用富有的皇帝与黄金宫殿表达「富有的」，避免食品「浓郁」义。 |
| free | 用鸟可自由离开笼子表达「自由的」，避免「免费」义。 |
| hot | 咖喱中有辣椒，明确表达「辣的」，避免温度义。 |
| hard / soft / rough / smooth | 分别用龟壳、兔毛、树皮、石头表达硬、软、粗糙、光滑。 |
| keep / take / ride / return | 分别表达保留纪念卡、拿走空盘、乘坐过山车、返回鸟巢。 |
| chicken / honey / pork / sugar | 分别按鸡肉与不可数食物使用，不套用「a + 食物」。 |
| may / may not | 用请求许可和图书馆禁食表达「可以／不可以」，避免可能性义。 |
| Chinese / Maths / Computer Studies | 明确放在学校学科与课堂语境。 |
| give seats | 例句使用自然的 give our seats，允许短语中插入所有格。 |
| 序数词 | 分散使用页码、名次、楼层、队列和日期；校验日期存在及节日日期。 |
| pretend to be dead | 明示故事里的旅行者，保留故事语境。 |
| ugly | 描写旧垃圾桶，不用来评价孩子或其他人物。 |
